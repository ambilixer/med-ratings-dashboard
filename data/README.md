# Data

## `drugscom_ratings_long.csv`

The table the dashboard uses. It has one row per drug per Drugs.com condition page, plus one row per drug for each combined view:

| `condition` value | What it is | Drugs |
| --- | --- | --- |
| `Depression` | Drugs.com's Depression page | 54 |
| `Major depressive disorder` | Drugs.com's Major Depressive Disorder page | 26 |
| `Bipolar disorder` | Drugs.com's Bipolar Disorder page | 36 |
| `Major depression` | Depression + Major depressive disorder, combined | 59 |
| `Total` | All three pages combined | 77 |

The dashboard shows only the last three, plus `Bipolar disorder`. The two raw depression pages are kept for reference.

| Column | Meaning |
| --- | --- |
| `generic_name` | Generic drug name. Brand-name listings are folded into their generic. |
| `condition` | Condition page or combined view (see above). |
| `brand_names` | Brand names for the drug, separated by `; `. Includes brands listed on any page plus common brands added by hand. |
| `drug_class` | Pharmacological class, assigned for this project (not by Drugs.com). |
| `class_group` | Broader group: Antidepressant, Antipsychotic, Mood stabilizer / anticonvulsant, Other prescription, or Supplement. Assigned for this project. |
| `rating` | Average patient rating out of 10, one decimal. Blank if there are no reviews. Combined views use the review-weighted average. |
| `reviews` | Number of reviews. Combined views add the counts across pages. |
| `rx_otc` | `Rx`, `OTC` or `Rx/OTC`, as listed on Drugs.com. |
| `label_status` | `On-label` or `Off-label` for that condition, per Drugs.com's flag. A combined view counts a drug as off-label only if it is off-label on every page included. |
| `new_approval` | `yes` if Drugs.com tags the drug as a new approval on any page. |
| `conditions_listed` | Which of the three Drugs.com pages list the drug. |
| `pregnancy_cat` | Pregnancy category as shown on Drugs.com (A, B, C, D, X; N = not classified; blank = not shown). |
| `csa_schedule` | Controlled Substances Act schedule as shown on Drugs.com (2 to 5; N = not controlled; U = unknown). |
| `alcohol_interaction` | `yes` if Drugs.com flags an alcohol interaction. |

## `drugscom_listings.csv`

Every listing exactly as it appears on each Drugs.com page, before brand and generic listings are merged: `condition`, `listing_name`, `off_label`, `new_approval`, `rating`, `reviews`, `rx_otc`, `pregnancy_cat`, `csa_schedule`, `alcohol_interaction`, `generic_name`, `is_brand_listing`.

## `drug_meta.json`

Generated by `scripts/make_meta.py`. It holds the brand-to-generic map, drug classes, class groups and extra brand names. Edit `make_meta.py` rather than this file.

## `raw/`

Your local copies of the Drugs.com page text. These aren't published; see [`raw/README.md`](raw/README.md).
